# 🎓 Student Management System

A full-stack **Student Management System** built using **Spring Boot, Spring Security, Thymeleaf, and MySQL**.  
This project allows administrators to manage students, courses, and enrollments through a secure dashboard.

---

## 🚀 Features

- Secure authentication with **Spring Security**
- Add, update, delete students
- Manage courses
- Enroll students into courses
- Dashboard analytics
- Pagination support
- Responsive UI with Bootstrap

---

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Bootstrap
- Maven

---

## 📊 Project Modules
